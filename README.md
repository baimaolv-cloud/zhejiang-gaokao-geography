# 浙江新高考地理选考一本通

一份面向浙江新高考（选考）地理的备考资料，按「真题 · 考点 · 解析 · 易混点 · 易错点 · 破解策」六个维度组织，并包含知识图谱、命题人视角与互动自测。

## 内容结构

- 考情概览（100 分 / 90 分钟，25 选择 + 3 综合，自然 ≈53% / 人文+区域+国安 ≈47%）
- 知识图谱（SVG 思维导图，可点击跳转）
- 命题人视角（命题意图 / 设坑点 / 评分要点拆解）
- 自然地理五大规律（地球运动、大气、水体、地壳物质、地域分异）
- 人文地理四大区位（农业、工业、城市与服务业、人口与资源）
- 区域 · 资源 · 国家安全
- 易混易错速查表（45 条）
- 针对性破解策（6 法）
- 真题自测闯关（38 道已逐题核验的真实浙江选考真题，随机抽题即时判分）

## 真题真实性

文档内所有标注「真题」的题组均逐项比对浙江省教育考试院官方试卷与《选考试题评析》，题号、选项、答案一致，无编造；示意图均为「据题述重绘」的示意还原。
